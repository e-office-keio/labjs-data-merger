# 🧪 lab.js 実験データ結合ツール

lab.jsで収集した複数のCSVファイルを一括でアップロードし、1被験者1行（ワイド形式）のデータにまとめてダウンロードできるWebアプリケーションです。

## 🚀 使い方

1. アプリURLにアクセスします。
2. データ結合したい CSV ファイル（複数可）をドラッグ＆ドロップまたは選択してアップロードします。
3. 「データを結合して処理する」ボタンをクリックします。
4. 処理結果をプレビューし、「💾 まとめCSVファイルをダウンロード」をクリックして保存します。

## 🛠️ 主な機能
- 被験者基本情報（`participantID`, `age`, `sex`, `condition`）の抽出
- クイズ正答率・平均反応時間の自動計算
- アンケート自由記述・質問項目（`q1.`, `q2.`, `purpose` など）の自動結合
- UTF-8 BOM付きCSVのダウンロード（Excelで文字化けせずに開けます）
