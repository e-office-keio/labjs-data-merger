# 🧪 lab.js 汎用実験データ結合・統計解析用整形ツール

任意の **lab.js** 実験で収集した複数のCSVファイルを一括でアップロードし、SPSS / R / Python / Jamovi / JASP 等での統計解析にそのまま使える **1被験者1行（ワイド形式）** のデータセットに自動整形・ダウンロードできるWebアプリケーションです。

## 🚀 使い方

1. アプリを起動（またはデプロイ先URLにアクセス）します。
2. 結合したい lab.js の CSV ファイル（複数可）をドラッグ＆ドロップまたは選択してアップロードします。
3. **「⚙️ 抽出・展開ルールの確認とカスタマイズ」** に自動検出された列分類が表示されます（そのままでも実行可能ですが、必要に応じて抽出列や展開ルールを画面上で変更できます）。
4. **「📊 統計解析用ワイドデータセット（1被験者1行）を作成する」** ボタンをクリックします。
5. プレビューを確認し、**「💾 統計解析用まとめデータ (summary_stats_data.csv) をダウンロード」** をクリックして保存します。

## 🛠️ 主な機能

- **全自動の列構造スキャン＆画面上でのカスタマイズ**
  - lab.js のシステム標準列（`sender`, `timestamp`, `time_*`, `meta.*` など）を自動判別して除外し、実験者が定義したすべての変数を自動分類します。
- **単一値列（アンケート・属性・実験条件など）の全自動抽出**
  - 特定の変数名に依存せず、1被験者につき1つの値を持つすべての質問項目・属性・条件・集計スコア列を自動抽出します。
- **複数行に値がある列（自由記述・自由再生など）の連番展開**
  - 1人の被験者が複数行にわたって回答した項目（例：`recall` 等）を自動的に `列名_1`, `列名_2`, ... として横展開します。
- **課題（トライアル）データの横展開＆全体集計**
  - 刺激語（`worditem`, `stimulus` 等）や問題番号（`itemNO`, `trial_id` 等）のキー列ごとに、各試行の反応時間（`rt_...`）・正誤（`corr_...`）・回答値（`resp_...`）を横展開します。
  - 課題ごとの正答数・試行総数・正答率（%）・全体平均RT・正答試行のみの平均RTを自動計算します。
- **日本語の列名・刺激語のローマ字（ASCII英数字）自動変換**
  - 漢字・ひらがな・カタカナを含む列名や刺激語を、`pykakasi` および内蔵のかな→ローマ字変換エンジンでクリーンな ASCII 英数字変数名に自動変換します（ON/OFF 切替可）。
- **Excel でも文字化けしない UTF-8 BOM 付き CSV 出力**
